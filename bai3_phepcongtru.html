I

LÝ THUYẾT TRỌNG TÂM

1) Cộng, trừ hai đa thức

Ví dụ 1: Cho hai đa thức $A = 3x + y - z$ và $B = 4x - 2y + 6z$

Khi đó tổng hai đa thức $A$ và $B$ là:

$$A + B = 3x + y - z + 4x - 2y + 6z = (3x + 4x) + (y - 2y) + (-z + 6z) = 7x - y + 5z$$

Và hiệu hai đa thức $A$ cho đa thức $B$ là :

$$A - B = 3x + y - z - (4x - 2y + 6z) = 3x + y - z - 4x + 2y - 6z = -x + 3y - 7z$$

Kết luận:

  • ♣ Cộng hay trừ hai đa thức là thu gọn đa thức nhận được sau khi nối hai đa thức đã cho bởi dấu "+" hay dấu "-" .
  • ♣ Phép cộng đa thức cũng có các tính chất như giao hoán, kết hợp như phép cộng các số .
II

LUYỆN TẬP MẪU

3 bài tập mẫu có lời giải
Bài 1 (Mẫu)

Thực hiện phép tính: $\left(-5x^2y + 3xy^2 + 7\right) + \left(-6x^3y + 4xy^2 - 5\right)$

Lời giải
$$= -5x^2y + 3xy^2 + 7 - 6x^3y + 4xy^2 - 5$$ $$= -5x^2y + (3xy^2 + 4xy^2) - 6x^3y + 2 = -5x^2y + 7xy^2 - 6x^3y + 2$$
Bài 2 (Mẫu)

Thực hiện phép tính: $\left(4x^2 + x^2y - 5y^2\right) - \left(x^3 - 6xy^2 - x^2y\right)$

Lời giải
$$= 4x^2 + x^2y - 5y^2 - x^3 + 6xy^2 + x^2y$$ $$= 4x^2 + (x^2y + x^2y) - 5y^2 - x^3 + 6xy^2 = 4x^2 + 2x^2y - 5y^2 - x^3 + 6xy^2$$
Bài 3 (Mẫu)

Cho đa thức $A = x^5y + 3x^4 + 5x^2y$, $B = 2xy - 3x^4 - 2xy + 9 + 2x^2y$ .

  • a) Tính $C = A + B$
  • b) Tính giá trị của $C$ tại $x = -1, y = 2$ .
Lời giải

a) $C = A + B = x^5y + 3x^4 + 5x^2y + 2xy - 3x^4 - 2xy + 9 + 2x^2y$

$$= x^5y + (3x^4 - 3x^4) + (5x^2y + 2x^2y) + (2xy - 2xy) + 9 = x^5y + 7x^2y + 9$$

b) Tại $x = -1, y = 2$: $C = (-1)^5 \cdot 2 + 7 \cdot (-1)^2 \cdot 2 + 9 = -2 + 14 + 9 = \mathbf{21}$.

Dạng 3: Biểu thức ngoặc lồng nhau và rút gọn đa thức phức tạp (Bài 4 – Bài 10)[cite: 10, 11]

Bài 4 – Bài 10: Thu gọn các biểu thức đa thức chứa ngoặc[cite: 10, 11]:
Bài 4: Cho $A = \left(\dfrac{1}{3}a - \dfrac{1}{3}b\right) - (a - 2b)$ và $B = \dfrac{1}{3}a - \dfrac{1}{3}b - (a - b)$. Tính $A + B$ và $A - B$.
Bài 5: Cho $C = x - [b - (c - a - b)]$ và $D = b + [a - (c - b - a)]$. Tính $C + D$ và $C - D$.
Bài 6: Cho $E = y - [y - (y + 2x - x)]$ và $F = y - [y - x + 2(x - y)]$. Tính $E + F$ và $E - F$.
Bài 7: Cho $G = \left[\dfrac{1}{2}ax - 2(ax + 3)\right] - (ax + 1)$ và $H = ax - 2 - [-(ax - 1) + 3] - 4$. Tính $G + H$ và $G - H$.
Bài 8: Cho $M = [x + (y - z) - 2x] + y + z - (2 - x - y)$ và $N = x - [x - (y - z) - x]$. Tính $M + N$ và $M - N$.
Bài 9: Cho $P = a^2 - 2ab + 3b^2$ và $Q = 2a^2 - 3ab - b^2 + \left(-3a^2 + 2ab - b^2\right)$. Tính $P + Q$ và $P - Q$.
Bài 10: Cho $I = 3a^2 + b^2 - \left(ab - a^2\right)$ và $K = 2a^2 + ab - b^2 - \left(-a^2 + b^2 - ab\right)$. Tính $I + K$ và $I - K$.
Xem lời giải chi tiết Bài 4 – 10
Bài 4: $A = -\dfrac{2}{3}a + \dfrac{5}{3}b$; $B = -\dfrac{2}{3}a + \dfrac{2}{3}b$. $A + B = -\dfrac{4}{3}a + \dfrac{7}{3}b$; $A - B = b$.
Bài 5: $C = x + b - c + a$; $D = b + a - c + b = a + 2b - c$. $C + D = x + 2a + 3b - 2c$; $C - D = x - 2b$.
Bài 6: $E = x + y$; $F = x - y$. $E + F = 2x$; $E - F = 2y$.
Bài 7: $G = -\dfrac{3}{2}ax - 7$; $H = 2ax - 6$. $G + H = \dfrac{1}{2}ax - 13$; $G - H = -\dfrac{7}{2}ax - 1$.
Bài 8: Thu gọn $M = 3y + 2z - 2$; $N = x - y + z$. $M + N = x + 2y + 3z - 2$; $M - N = -x + 4y + z - 2$.
Bài 9: Thu gọn $P = a^2 - 2ab + 3b^2$; $Q = -a^2 - ab - 2b^2$. $P + Q = -3ab + b^2$; $P - Q = 2a^2 - ab + 5b^2$.
Bài 10: Thu gọn $I = 4a^2 - ab + b^2$; $K = 3a^2 + 2ab - 2b^2$. $I + K = 7a^2 + ab - b^2$; $I - K = a^2 - 3ab + 3b^2$.

Dạng 4: Chuỗi đa thức nâng cao & Tính giá trị (Bài 11 – Bài 18)

Bài 11 – Bài 18: Bài tập nâng cao hệ thống đa thức :
Bài 11: Cho $A = 2x^4 - x + 3x^2 - 6$, $B = -x^4 + 2 - 3x^2 - 5x$ và $C = -2x^3 + 1 - 3x + x^2$. Tính $M = A - B + C$, $N = B - C - A$, $P = C - A - B$.
Bài 12: Cho $A = 5x^3y - 4xy^2 - 6x^2y^2$, $B = -8x^3y + xy^2 - 4x^2y^2$ và $C = x^3 + 4x^3y - 6xy^3 - 4xy^2 + 5x^2y^2$. Tính $A - B - C$, $B + A - C$, $C - A - B$.
Bài 13: Cho các đa thức $A = 16x^4 - 8x^3y + 7x^2y^2 - 9y^4$, $B = -15x^4 + 3x^3y - 5x^2y^2 - 6y^4$ và $C = 5x^3y + 3x^2y^2 + 17y^4 + 1$. Tính $A + B - C$, $A - C + B$.
Bài 14: Cho $A = 4x^2 - 5xy + 3y^2$, $B = 3x^2 + 2xy + y^2$ và $C = -x^2 + 3xy + 2y^2$. Tính $A + B + C$, $B - C - A$, $2A - 3B - C$.
Bài 15: Cho $A = x^2 - 3xy - y^2 + 2x - 3y + 1$, $B = -2x^2 + xy + 2y^3 - 3 - 5x + 2y$ và $C = 7y^2 + 3x^2 - 4xy - 6x + 4y + 5$. Tính $A + B + C$, $7A - B - C - 9$, $A - 4B - 3C$.
Bài 16: Cho $A = 5xy^2 - 4x^2y - 6x^2$, $B = 8yx^2 - 4y^2x + 3y^2$ và $C = -2xy^2 + 3yx^2 + 5x^2$. Tính $A - B + C$, $2(A + B) + C$.
Bài 17: Cho hai đa thức $A = x^2 - 3xy - y^2 + 1$ và $B = 2x^2 + y^2 - 7xy - 5$.
a) Tính $A + B$.
b) Tìm đa thức $C$ biết $C + A - B = 0$.
c) Tính giá trị của $C$ với $x = 2, y = \dfrac{-1}{2}$.
Bài 18: Cho $P(x) = 5x^2 + 5x - 4$, $Q(x) = 2x^2 - 3x + 1$ và $R(x) = 4x^2 - x + 3$. Tính $P(x) + Q(x) - R(x)$ rồi tính giá trị của đa thức tại $x = \dfrac{-1}{2}$.
Xem lời giải chi tiết Bài 11 – 18
Bài 11: $M = 3x^4 - 2x^3 + 6x^2 + 4x - 7$; $N = -3x^4 + 2x^3 - 6x^2 - 4x + 7$; $P = -3x^4 + 2x^3 - 6x^2 - 4x + 7$.
Bài 12: $A - B - C = 2x^3y + 6xy^3 - 7x^2y^2 - x^3$; $B + A - C = -2x^3y + 6xy^3 - 17x^2y^2 - x^3$; $C - A - B = 6xy^3 + 7x^2y^2 + x^3 - 2x^3y$.
Bài 13: $A + B - C = x^4 - 16x^3y + 9x^2y^2 - 30y^4 - 1$; $A - C + B = x^4 - 16x^3y + 9x^2y^2 - 30y^4 - 1$.
Bài 14: $A + B + C = 6x^2 + 6xy + 6y^2$; $B - C - A = -2x^2 + 4xy - 2y^2$; $2A - 3B - C = -2x^2 - 19xy - 2y^2$.
Bài 15: Thu gọn và tính toán theo yêu cầu từng câu tương ứng với bậc đa thức.
Bài 16: $A - B + C = 3xy^2 - 15x^2y + 4x^2 + 3y^2$; $2(A + B) + C = 24xy^2 - 16x^2y - 7x^2 + 9y^2$.
Bài 17: a) $A + B = 3x^2 - 10xy + y^2 - 4$; b) $C = B - A = x^2 - 4xy + 2y^2 - 6$; c) Thay $x = 2, y = -\dfrac{1}{2}$ vào $C$ ta được giá trị là $\dfrac{27}{2}$.
Bài 18: $P(x) + Q(x) - R(x) = 3x^2 + 9x - 6$. Tại $x = -\dfrac{1}{2}$, giá trị là $3\left(-\dfrac{1}{2}\right)^2 + 9\left(-\dfrac{1}{2}\right) - 6 = \dfrac{3}{4} - \dfrac{9}{2} - 6 = -\dfrac{39}{4}$.
